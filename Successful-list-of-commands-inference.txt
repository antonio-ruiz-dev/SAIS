		Why AUC doesn't give NaN during training but does during inference with a single gesture class:

		## The Problem

		**During inference**: When running inference on a single video that contains only **one gesture class**, the `labels` array has only one unique class value. The `roc_auc_score()` function requires **at least 2 classes** to compute ROC AUC (you need two classes to define the true positive rate vs false positive rate trade-off). When only one class is present, it raises an exception which is caught on prepare_miscellaneous.py and returns `np.nan`.

		**During training/validation**: Even though your model is trained on `Custom_Gestures`, the validation batches during training contain **multiple gesture classes** sampled from the validation dataset. Since multiple classes are present, AUC can be computed without error.

		## The Root Cause

		The code in prepare_miscellaneous.py doesn't check the number of unique classes before calling `roc_auc_score()`:

		```python
		try:
			auc = roc_auc_score(labels, probs, multi_class='ovr')
		except:
			auc = np.nan
		```

		When inference runs on data with only one gesture class, the exception is triggered and caught silently.

		## Solution

		You should add an explicit check before computing AUC to handle single-class data gracefully:

		```python
		unique_classes = len(np.unique(labels))
		if unique_classes < 2:
			auc = np.nan  # AUC undefined with fewer than 2 classes
		else:
			try:
				auc = roc_auc_score(labels, probs, multi_class='ovr')
			except:
				auc = np.nan
		```

		This way, you'd get a clear `nan` value rather than an exception, and it would be intentional and documented.

		The warning says only **one class is present in `y_true`** during inference. This means all samples in your inference set belong to the same gesture class — `roc_auc_score` requires at least two classes to compute AUC. The code catches the exception and returns `np.nan` ([prepare_miscellaneous.py line ~166](SAIS/scripts/prepare_miscellaneous.py#L166)):

		```python
			auc = roc_auc_score(labels, probs, multi_class='ovr')
		except:
			auc = np.nan
		```
