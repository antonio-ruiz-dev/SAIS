	Here is exactly how NCE loss is computed in this codebase, as implemented in prepare_miscellaneous.py:14:

	Step 1 — Normalize prototypes
		p = stack of all learned prototype vectors   # shape: nclasses × D
		p_norm = p / ||p||                           # L2-normalize each prototype
	Step 2 — Normalize video representation
		s = snip_sequence                            # shape: nbatch × D
		s_norm = s / ||s||                           # L2-normalize each sample
	Step 3 — Compute cosine similarities
		sim = s_norm @ p_norm.T                      # nbatch × nclasses
		sim_exp = exp(sim)                           # exponentiate (like softmax numerator)
	Step 4 — Identify the positive prototype per sample
		cols = index of prototype matching the sample's ground-truth label
		nums = sim_exp[row, col]                     # positive similarity (numerator)
		dens = sum(sim_exp, axis=1)                  # sum over ALL prototypes (denominator)	

	Step 5 — Compute the final scalar loss
		loss = -mean( log(nums / dens) )
