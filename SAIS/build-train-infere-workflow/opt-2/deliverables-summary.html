🚀 Quick Start (3 Steps)

Step 1: Setup SAIS (30 minutes)

git clone https://github.com/danikiyasseh/SAIS.git conda create -n SAIS python=3.9.7 pip install -r requirements.txt && pip install -e . # Download DINO weights # Modify PyTorch transformer

Step 2: Install Agent (1 minute)

cp sais_agent.py /path/to/SAIS/

Step 3: Run Workflow (1-2 hours)

python sais_agent.py \ --sais_root . \ --dino_weights ./SAIS/scripts/dino-main/outputs/dino_deitsmall16_pretrain.pth \ --training_videos video_1 video_2 \ --inference_videos test_video \ --epochs 50 \ --batch_size 8 \ --num_classes 10
